Tipos de Datos en JavaScript

Primitivos: Se accede diractamente al valor. Para saber el tipo de datos de una variable de usa typeof

  • string: Cadena de Texto. Se convierte a numero con la funcion Number.
  • number: Valor numérico
  • bigint: Numeros enteros mayores a 9007199254740991(2-1). Se representan anadiendo una n al final del numero.
  • boolean: Valor logico Verdadero/Falso. (ver Falsy y Truthy)
  • null: La variable tiene como valor, vacio.
  • undefined: La variable ha sido declarada pero no tiene valor.
  • NaN: Not a Number (no es un numero)

Compuestos: Se accede la referencia del volar. Lavariable no guarda los datos, guarda la "ubicacion" en la memoria donde estan esos datos. Si dos variables apuntan a la misma direccion y una cambia algo, la otra tambien lo vera cambiado. Para saber el tipo de objeto que se esta trabajando se utiliza instanceof.

  • Object: Cadena de Texto. Se convierte a numero con la funcion Number.
  • array: Valor numérico
  • function(): Numeros enteros mayores a 9007199254740991(2-1). Se representan anadiendo una n al final del numero.
  • Class: Valor logico Verdadero/Falso. (ver Falsy y Truthy)
